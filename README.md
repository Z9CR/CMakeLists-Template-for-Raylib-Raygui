## How to use it
1. make sure that CMake is installed on your PC
2. put [CMakeLists.txt](https://github.com/Z9CR/CMakeLists-Template-for-Raylib-Raygui/blob/main/CMakeLists.txt) into your project directory
3. run `cmake -B build; cmake --build build` in your terminal
(P.S. If you want to build it in another directory, for example `./Auild`, you can just run `cmake -B Auild; cmake --build Auild`)
4. check the build directory and run the executable
